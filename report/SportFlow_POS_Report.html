PROJECT OVERVIEW

บทสรุปโครงงาน

SportFlow POS เป็นระบบบริหารงานขายหน้าร้านสำหรับร้านขายอุปกรณ์กีฬา ออกแบบให้พนักงานทำรายการขายได้รวดเร็ว และช่วยให้ผู้จัดการตรวจสอบสต็อก สมาชิก พนักงาน และรายงานยอดขายได้จากระบบเดียว

BACKGROUND

1. ความเป็นมาของ Assignment

ธุรกิจค้าปลีกอุปกรณ์กีฬามีสินค้าหลากหลายประเภท เช่น รองเท้า ลูกบอล เสื้อผ้า อุปกรณ์ฟิตเนส และอุปกรณ์เฉพาะชนิดกีฬา แต่ละรายการมีราคา ต้นทุน และจำนวนคงเหลือแตกต่างกัน การบันทึกยอดขายด้วยกระดาษหรือโปรแกรมตารางทั่วไปทำให้ตรวจสอบสต็อกได้ช้า มีโอกาสคำนวณผิด และไม่สามารถเห็นภาพรวมยอดขายได้ทันที

แรงบันดาลใจของโครงงานมาจากการต้องการสร้างระบบที่ช่วยให้ร้านขนาดเล็กถึงขนาดกลางทำงานอย่างเป็นระบบ โดยนำแนวคิด Point of Sale (POS) มารวมกับการบริหารสมาชิกและข้อมูลวิเคราะห์การขาย ระบบจึงใช้ชื่อว่า SportFlow ซึ่งสื่อถึงขั้นตอนการทำงานที่ไหลลื่น ตั้งแต่เลือกลูกค้า เลือกสินค้า ชำระเงิน ออกใบเสร็จ ไปจนถึงสรุปรายงาน

Assignment นี้เป็นการนำความรู้ด้าน Laravel Framework, MVC, Blade Template, Eloquent ORM, ฐานข้อมูลเชิงสัมพันธ์, validation, transaction และการออกแบบส่วนติดต่อผู้ใช้มาประยุกต์ในสถานการณ์จริงที่มีความสัมพันธ์ของข้อมูลหลายส่วน

ทำให้จำนวนสินค้าคงเหลือเปลี่ยนตามรายการขายโดยอัตโนมัติ

03 / ความสัมพันธ์ลูกค้า

เก็บประวัติการซื้อ คะแนนสะสม และระดับสมาชิกอย่างต่อเนื่อง

04 / การตัดสินใจ

แสดงยอดขาย สินค้าใกล้หมด และสินค้าขายดีให้ผู้จัดการทราบทันที

2. วัตถุประสงค์ของ Assignment
